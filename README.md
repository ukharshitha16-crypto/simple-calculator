# Simple Verilog Calculator

A basic calculator implemented in Verilog HDL.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Simulation using Icarus Verilog
- Waveform viewing using GTKWave

## Operations

| Opcode | Operation |
|--------|-----------|
| 00 | Addition |
| 01 | Subtraction |
| 10 | Multiplication |
| 11 | Division |
